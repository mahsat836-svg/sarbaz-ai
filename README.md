# SARBAZ AI — төтенше жағдайдағы шешім тренажері

**БӘД (бастапқы әскери даярлық)** пәніне арналған оқу платформасы.
Автор: **А. Хайдаров**, БӘД оқытушы-ұйымдастырушысы, Ө. Жәнібеков атындағы жалпы білім беретін мектеп (Сауран ауданы, Түркістан облысы).

Педагогикалық тақырып: «Ауыл мектебі + ЖИ: төтенше жағдайға дайын — жеке сценарийлер арқылы әрекет етуді үйрену».

## Құрамы
| Бөлім | Сипаттама |
|---|---|
| `index.html` | Тренажер: 9 тармақталған сценарий (өрт, жер сілкінісі, су тасқыны), бастапқы/қорытынды тапсырма, ережеге негізделген бейімдеу, мұғалім панелі, CSV есеп, ЖИ көмегімен сценарий дайындау |
| `game.html` | **«Көшеге шық!»** — мектептің 2 қабатты картасы бойынша өз кабинетіңнен Ақынтоған көшесіндегі жиналу орнына эвакуация ойыны |
| `#jury` | Қазылар алқасына арналған бет: QR код, 3 қадамдық көрсетілім |
| `img/` | Мектептің эвакуация сызбасы (`evac1.jpg`, `evac2.jpg`, `evac2wall.jpg`) және марапаттар (`award1–4.jpg`) |

## Ерекшеліктері
- Тіркелусіз, тек бүркеншік ат — оқушының жеке деректері жиналмайды.
- PWA: бір рет ашылған соң интернетсіз жұмыс істейді, телефонға қосымша ретінде орнатылады.
- Нәтижелер құрылғыдағы браузерде сақталады.
- ЖИ тек мұғалім панелінде: сценарий жобасы мұғалім тексермейінше оқушыға берілмейді.

## Ескерту
Бұл — оқу тренажері. Ойын картасы мектептің эвакуация сызбасы негізінде жеңілдетіп салынған. Нақты төтенше жағдайда мектептің бекітілген жоспары мен ресми нұсқауларды орындаңыз.
